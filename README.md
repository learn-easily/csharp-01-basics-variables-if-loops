# Backend · ლექცია 1 — C#-ის სამყარო

სკოლის მოსწავლეების ჯგუფი (Frontend/Angular გავლილი). ანიმაციური HTML პრეზენტაცია + ლექტორის სცენარი.

| ფაილი | რა არის |
|---|---|
| `index.html` | პრეზენტაცია (46 სლაიდი) |
| `script.html` | ლექციის სცენარი — წასაკითხად / დასაბეჭდად |
| `deck/` | წყარო: სლაიდები და შენიშვნები (`c1.html`), ძრავი (`engine.*`), ბილდი (`build_c1.py`) |

## გეგმა (~2 სთ)

1. **შესავალი** — რა არის Backend (რესტორნის ანალოგია, „ყიდვის“ ღილაკი), კურსის გზა C# → MS SQL → EF Core → ASP.NET Core → Unity, რას შეძლებენ, VS 2026-ის ინსტალაცია (სახლში)
2. **როგორ მუშაობს C#** — კომპილატორი vs ბრაუზერი, პირველი Console App, Angular ↔ .NET ცნებები, სინტაქსის წესები
3. **ცვლადები** — ტიპები, მკაცრი ტიპიზაცია, `var`/`const` ხაფანგი, `$"…"`, `7 / 2 = 3`
4. **კონსოლი** — `WriteLine`/`Write`, ფერები, `ReadLine`, `int.Parse`, მინი-ანკეტა
5. **if** — JS-თან მსგავსება, 3 განსხვავება, ქულები, ატრაქციონი, ternary/switch
6. **ციკლები (თუ დრო დარჩა)** — for, რაკეტა, გაუსის ჯამი, while, „გამოიცანი რიცხვი“
7. **დავალებები ⭐→⭐⭐⭐**, შპარგალკა JS → C#, ქვიზი

## გამოყენება

1. გახსენი `index.html` Chrome-ში ან Edge-ში, გადაიტანე პროექტორზე, დააჭირე `F`.
2. დააჭირე `Ctrl+Shift+P` — გაიხსნება **ლექტორის ფანჯარა** სცენარით.
3. ნავიგაცია: `→` შემდეგი, `←` წინა. `O` ყველა სლაიდი (მაგ. ციკლების გამოტოვება).

## ცვლილების შეტანა

```bash
cd deck && pip install pygments && python3 build_c1.py
cp ../out/index.html ../index.html && cp ../out/script.html ../script.html
```
